# LVTHN-CODEC **RU** | [EN](https://github.com/FreshLend/LVTHN-CODEC/blob/main/README.EN.md)

Модульный, патентно-чистый и высокоэффективный медиа-кодек, написанный на Python. 
Он использует универсальный контейнер (`.lvn`), который поддерживает как **Аудио**, так и **Изображения**, применяя современные психоакустические и психовизуальные модели, чтобы превзойти промышленные стандарты вроде MP3 и PNG.

## Особенности

*   **Универсальный контейнер (`.lvn`):** Один формат для всего. Декодер автоматически определяет, что внутри.
*   **Аудиокодек:** MDCT + Mid/Side стерео + полосы Барка + Абсолютный порог слышимости (ATH) + Адаптивное квантование.
*   **Поддержка стриминга:** Аудио может быть закодировано в монолитном режиме (максимальное сжатие) или чанковом режиме (идеально для стриминга и низкого потребления памяти).
*   **Кодек изображений:** Цветовое пространство Oklab + Блочный DCT + RLE + Zstandard.
*   **Производительность:** 
    *   Аудио превосходит MP3 по размеру на ~15% при том же воспринимаемом качестве (до 3 раз на речи).
    *   Изображения превосходят PNG по размеру в 5-10 раз в зависимости от сложности контента.
    *   Высокая скорость: RTF аудио < 0.015, кодирование картинки занимает от 0.01 до 0.06 секунды в зависимости от разрешения.

## Установка

Убедитесь, что у вас установлен Python 3.10+.

```bash
pip install lvthn-codec sounddevice PySide6
```
*(Примечание: Для работы `converter.py` с форматами вроде MP3 или JPG необходимо установить `ffmpeg` и добавить его в системную переменную PATH).*

## Использование

### 1. CLI кодек
Прямое кодирование и декодирование с помощью установленной команды `lvthn`.
```bash
# Аудио (Монолитный режим)
lvthn encode track.wav track.lvn compact monolithic

# Аудио (Чанковый режим)
lvthn encode track.wav track.lvn compact chunked

# Изображения
lvthn encode-img image.png image.lvn fast

# Декодирование
lvthn decode track.lvn out.wav
lvthn decode-img image.lvn out.png

# Информация о файле
lvthn info track.lvn
```

### 2. Конвертер (`converter.py`)
Конвертирует любые поддерживаемые форматы (через ffmpeg) в `.lvn` и обратно.
```bash
python converter.py to-lvn track.mp3 track.lvn --profile default --mode chunked
python converter.py from-lvn track.lvn track_out.mp3 --bitrate 192k
```

### 3. Плеер (`player.py`)
Современный GUI-плеер и просмотрщик картинок на PySide6. Поддерживает плавную перемотку для обоих режимов аудио.
```bash
python player.py track.lvn
python player.py image.lvn
```

### 4. Бенчмарк (`benchmark.py`)
Тестирование скорости и степени сжатия на ваших файлах.
```bash
python benchmark.py --audio audio.wav --image image.png --image-profiles fast max --audio-modes monolithic chunked
```

## Профили

### Профили аудио
| Профиль | Описание | SNR | Для чего лучше всего |
|---|---|---|---|
| `compact` | Максимальное сжатие | 20.0 | Повседневное прослушивание, экономия места |
| `default` | Сбалансированный | 24.0 | Музыка высокого качества |
| `speech` | Оптимизация под голос | 20.0 | Подкасты, аудиокниги |
| `detail` | Сохраняет тихие детали | 24.0 | Lo-Fi, акустика, винил |
| `master` | Архивное качество | 30.0 | Мастеринг, студийные архивы |

### Профили изображений
| Профиль | Качество | Уровень Zstd | Для чего лучше всего |
|---|---|---|---|
| `fast` | 85 | 5 | Быстрый просмотр, текстуры для игр |
| `default` | 92 | 12 | Картинки для веба, повседневное использование |
| `max` | 98 | 19 | Архивация, профессиональная фотография |

## Бенчмарки

### Аудио (среднее по музыкальным трекам)
| Профиль | Режим | Битрейт | SNR | Enc RTF | Dec RTF |
|---|---|---|---|---|---|
| `compact` | Монолит | ~51 kbps | 23.2 dB | 0.010 | 0.010 |
| `compact` | Чанки | ~55 kbps | 23.2 dB | 0.080 | 0.050 |
| `default` | Монолит | ~58 kbps | 24.9 dB | 0.009 | 0.009 |
| `default` | Чанки | ~62 kbps | 24.9 dB | 0.077 | 0.048 |
| `speech` | Монолит | ~74 kbps | 28.1 dB | 0.010 | 0.009 |
| `detail` | Монолит | ~96 kbps | 32.4 dB | 0.010 | 0.009 |
| `master` | Монолит | ~114 kbps | 35.7 dB | 0.010 | 0.010 |

### Аудио (среднее по речевым записям)
| Профиль | Режим | Битрейт | SNR | Enc RTF | Dec RTF |
|---|---|---|---|---|---|
| `compact` | Монолит | ~43 kbps | 30.6 dB | 0.004 | 0.003 |
| `default` | Монолит | ~49 kbps | 32.7 dB | 0.004 | 0.003 |
| `master` | Монолит | ~88 kbps | 45.9 dB | 0.004 | 0.004 |

*(RTF < 0.015 означает кодирование в 60+ раз быстрее реального времени. Чанковый режим добавляет ~4 kbps overhead для поддержки стриминга).*

### Изображения (среднее по реальным фотографиям)
| Профиль | PSNR | Время Enc | Время Dec | Сжатие |
|---|---|---|---|---|
| `fast` | 39.9 dB | 0.01s | 0.01s | 7.8x |
| `default` | 42.9 dB | 0.02s | 0.01s | 5.6x |
| `max` | 47.5 dB | 0.06s | 0.01s | 3.0x |

*(PSNR > 40 dB считается визуально неотличимым от оригинала. Большие коэффициенты сжатия достигаются на простых изображениях, меньшие - на текстурных фотографиях).*

## Архитектура

*   `lvthn/codec.py` - Основной CLI и API.
*   `lvthn/core/container.py` - Универсальная обёртка LVTHN.
*   `lvthn/core/audio.py` - Математика аудио (MDCT, Bark, Psy).
*   `lvthn/core/image.py` - Математика изображений (Oklab, DCT).
*   `player.py` - Графический интерфейс (PySide6).
*   `converter.py` - Обёртка над FFmpeg.
*   `benchmark.py` - Инструмент тестирования производительности.
